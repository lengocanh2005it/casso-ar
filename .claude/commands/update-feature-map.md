Update feature-map.md status for a completed plan.

Usage: `/update-feature-map <plan-number> <pr-number>`

Example: `/update-feature-map 18 2`

Steps:
1. Open `docs/wayfinder/feature-map.md`
2. Find the plan section (e.g., "#### Plan #18")
3. Change `**Status**: open` → `**Status**: done ✅`
4. Add `**Shipped**: <date> — PR #<number> merged, <N> commits`
5. Update ticket count in Ticket Index
6. Update Frontier section if needed
7. Commit and push
